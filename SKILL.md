# Save a public webpage to Obsidian

Run the bundled publisher exactly once:

```bash
python3 ${CLAUDE_SKILL_DIR}/scripts/capture_and_publish.py
```

Do not run any other command. Do not add arguments, shell operators, redirects, pipes,
environment assignments, or command substitutions.

The publisher reads the sealed `.geof_cobs_task.json` in the current working directory.
It performs HTTPS-only retrieval, extracts article text, body images, tables, code blocks,
and recoverable LaTeX math, and creates a new note and new image files in the approved
Obsidian directories. Simple tables become Markdown tables; valid merged-cell tables become
sanitized HTML generated by the publisher. Code keeps its line breaks and indentation.
WeChat `data-formula` and KaTeX/MathJax TeX sources become Obsidian `$...$` or `$$...$$`
math; image-only formulas without embedded TeX cannot be recovered as text. It never copies
source HTML attributes or scripts, never overwrites an existing file, and emits only a compact
result manifest, not article content. For WeChat,
it uses browser-compatible request headers, requires the real article content marker, and
fails closed on access-challenge or verification pages before creating any file. The note
keeps the original submitted URL even when the server resolves it to another URL.

For `x.ai/news/...`, the publisher requires the page title marker, the scoped `prose` article
body, and `NewsArticle` JSON-LD. It excludes navigation and footer text, uses the structured
headline/author/date/description, and localizes the JSON-LD cover image when one is available.
If those article markers are missing, it fails before creating any file.

For public X Articles at `x.com/.../status/...`, the publisher requires both the visible
`x-article-body` marker and a complete article serialization. It accepts the current inline
`content_state` stream and the legacy Draft.js serialization, joins stream chunks in document
order, and rebuilds the article from ordered blocks. Cover and body images are localized and
inserted at their mapped positions; markdown cards, dividers, and embedded-tweet links are
kept. Video items use the poster image. Avatars, reply images, and other page chrome are
excluded. If a block, entity, media identifier, or image URL cannot be mapped completely, it
fails before creating any file instead of publishing a text-only fallback.

After the command succeeds, report the returned repository-relative note path, image count,
and math count. If the command fails, report the exact failure without claiming that a note
was saved.
